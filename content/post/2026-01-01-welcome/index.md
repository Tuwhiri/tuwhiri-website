To write a news item:

1. Copy this folder and rename it, for example `2026-03-14-first-balloon-flight`.
2. Change the `title`, `summary` and `date` above.
3. Set `authors` to the folder names used in `content/authors/`.
4. Set `tags` to one of `atmospheric-science`, `photonics` or `engineering` so
   the item also appears on that research area page. You can use more than one.
5. Write the article here, below the second `---`, in ordinary sentences.
6. To add a picture, put a file called `featured.jpg` in the same folder.
